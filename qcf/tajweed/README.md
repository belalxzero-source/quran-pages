# Tajweed page fonts (layered)

One font per mushaf page (`pN.ttf`, N = 1..604) derived from the Quran Foundation's
QCF V4 tajweed page fonts (https://verses.quran.com/fonts/quran/hafs/v4/colrv1/ttf/pN.ttf,
King Fahd Glorious Quran Printing Complex glyphs, Dar al-Ma'rifa tajweed colouring).

The COLR/CPAL colour layers of each glyph are split into ten monochrome "role"
glyphs so that a renderer with no colour-font support (Flutter's Impeller) can
draw them stacked, each in its own colour. For the page code `cp` (U+F000..U+FFFF)
role `r` is at `U+F0000 + r*0x1000 + (cp - 0xF000)`; the BMP code keeps the full
glyph. Vertical metrics are those of the V2 page fonts (`../fonts`).

Roles: 0 base text · 1 grey (silent, hamzat wasl, lam shamsiyya) · 2 dark red (madd 6) ·
3 orange (madd 2-4-6) · 4 gold (madd 2) · 5 green (ghunnah) · 6 blue (tafkhim) ·
7 cyan (qalqalah) · 8 red (madd 4-5) · 9 ayah-marker ornament. The marker's fill
layer is dropped. `pN.json` lists, per code, a bit mask of the roles it has.
