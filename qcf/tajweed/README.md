# Tajweed page fonts (layered)

One font per mushaf page (`pN.ttf`, N = 1..604) derived from the Quran Foundation's
QCF V4 tajweed page fonts (https://verses.quran.com/fonts/quran/hafs/v4/colrv1/ttf/pN.ttf,
King Fahd Glorious Quran Printing Complex glyphs, Dar al-Ma'rifa tajweed colouring).

The COLR/CPAL colour layers of each glyph are split into up to ten monochrome
"role" glyphs so that a renderer with no colour-font support (Flutter's Impeller)
can draw them stacked, each in its own colour. Each role glyph sits at a spare
code of the Arabic Presentation Forms blocks (FB50–FDCF, FDF0–FDFF, FE70–FEFF)
not used by the page itself; `pN.json` maps each page code to its role codes
(`{"roles":10,"map":{"fc57":{"0":"fb8a","5":"fb8b"}}}`). The page's own code
keeps the full glyph. Vertical metrics are those of the V2 page fonts (`../fonts`).
(Supplementary-plane codes were tried first and crashed the Android emulator.)

Roles: 0 base text · 1 grey (silent, hamzat wasl, lam shamsiyya) · 2 dark red (madd 6) ·
3 orange (madd 2-4-6) · 4 gold (madd 2) · 5 green (ghunnah) · 6 blue (tafkhim) ·
7 cyan (qalqalah) · 8 red (madd 4-5) · 9 ayah-marker ornament. The marker's fill
layer is dropped.

Data © Quran Foundation / KFGQPC, used under the Quran Foundation developer terms
(https://quran.foundation). Generated by the Daily Quran Share app's tooling.

Generation 3 (2026-11-23): the V4 fonts carry hollow rectangle frames around some
tanween/kasra (palette-14 layers); the V2 fonts have no such contour anywhere, so
these artefacts are stripped from every glyph here. Generation 4: slanted (parallelogram) frames stripped too. Clients fetch `?v=4`.
