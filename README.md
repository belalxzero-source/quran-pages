# Daily Quran Share — static assets

Mushaf page images (Hafs, King Fahd Glorious Quran Printing Complex edition) as WebP, `pages/1.webp` … `pages/604.webp`,
served to the Daily Quran Share app via GitHub Pages. Derived from the public-domain set published by
[QuranHub/quran-pages-images](https://github.com/QuranHub/quran-pages-images) (The Unlicense).

`privacy.html` — the app's privacy policy (Arabic + English).
